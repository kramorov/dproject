# Агрегатор технической информации по управляемой трубопроводной арматуре и устройствам по управлению арматурой

**Миссия проекта:** лёгкость получения технической информации, умный поиск оборудования, быстрое получение информации об остатках и ценах, формирование пакета документов для клиентов

**Архитектура:** экосистема из трёх ключевых ИТ-продуктов:
1. Структурированное хранилище технической информации
2. Сайт-Агрегатор (каталоги и конфигураторы оборудования, система формирования КП, спецификаций, паспортов и технической информации на оборудование, система оформления заказов на покупку)
3. Сеть Сайтов-партнёров (внешние витрины клиентов, интегрированные через мини-приложения)

**Ключевой принцип:** площадка выступает агрегатором информации, а не продавцом — клиент получает выбор поставщика после формирования потребности. Это снимает конфликт интересов и повышает доверие всех сторон.

## 1. Возможности системы

### 1.1. Каталог и поиск

- **Каталог товаров**, представленный на четырёх вариантах:
- **Просмотр по сериям** – для детального просмотра карточек товара
  - **Быстрый подбор** – для быстрого выбора модели, не погружаясь в технические параметры
  - **Инженерный подбор** - **Умный поиск** по техническим параметрам (каскадные параметры, примерные аналоги) — не общий поиск от CMS.
- **AI-помощник подбора**:-
- **: единая строка поиска** — обработка запроса на естественном языке (вместо ручного листания каталога).
- **: большая гибкость запроса** — подбери аналог артикул ХХХ, «подбери пневмопривод к затвору ABRA ХХХ», «найди среди брендов А, B, C», «остаток, сроки поставки», «нужен сертификат».
- **ИИ-помощник** в каталогах: помогает выбрать оборудование, составляет фильтры, показывает карточки товара, отвечает на вопросы.
- **ИИ-помощник в конфигураторах:** подбирает состав сборки из каталога с приоритетом товаров с флагом «Проверено производителем».

- **Решение проблемы составных изделий:** для оборудования с комбинациями опций количество карточек может достигать миллионов — индексация роботами невозможна, SEO-оптимизация не работает. Решение — ИИ-поиск.
- ** Техническая документация, сертификаты, чертежи, схемы привязаны к модели и серии, хранятся в оптимизированном для просмотра на экране (быстрый просмотр), сжатом (отправка на почту с лимитом на объем вложений), полном – для скачивания и печати. Для формирования всех вариантов используются встроенные инструменты
- **структурированная информация schema для внешних ИИ-агентов** — задел на будущее, когда многие перейдут на агентские закупки.

### 1.2. Коммерческое предложение (КП)

- **Формирование «идеального КП»**, включающего:
  - Коммерческую часть (цена, сроки поставки, коммерческие условия)
  - Техническое описание каждой единицы в составе сборки
  - Габаритный чертеж сборки и/или каждого изделия в составе
  - Электрическую схему подключения (для ЭП, БКВ, клапана, позиционера)
  - Пневматическую схему
  - Сканы всех сертификатов на каждый компонент
  - Технический паспорт на сборку с указанием всех компонентов и их характеристик
  - Руководство по эксплуатации на сборку (адаптированное) или на компоненты
- **Автоматическая генерация документов «на лету»** — сбор информации и документов из разных источников автоматизирован.
- **Хранение КП + техдокументации на диске**, выдача ссылок для скачивания клиентам.
- **Сертификаты, технички, паспорта** доступны для скачивания в двух форматах: оригинал от производителя и сжатый (пригодный для отправки по email).
- **защита подбора** — описание для КП формируется достаточно полным и обезличенным, так как КП часто включается в другое КП изготовителями арматуры.

### 1.3. Инженерные инструменты

- **Конфигураторы** для проектирования уникальных, сложных или составных изделий по индивидуальным техническим требованиям.
- **Формирование BOM/EBOM** с возможностью проставлять наценки, искать замену по параметрам, видеть сроки поставки по каждой позиции.
- **Автоматический или ручной запрос цены и сроков у производителей** — внутри системы или через почту.
- **Интерактивные конфигураторы** с правилом изоляции номенклатуры: сконфигурированное оборудование сохраняется только в личную рабочую номенклатуру пользователя и не публикуется в общем каталоге.
- **таблицы соответствий** «арматура-привод» закрывают большинство стандартных запросов.
- **конструктор для нестандартных условий** (например, давление питания в пневмосистеме, нестандартные схемы электроподключений).

### 1.4. ИИ-модуль (автоматизация рутины)

- **Распознавание ОЛ, спецификаций, текстовых запросов клиентов:** ИИ парсит неструктурированные текстовые или табличные файлы (Excel, PDF, сканы) и мгновенно формирует системный документ «Запрос клиента», являющийся структурированным описанием требований клиента к оборудованию или сборке
- **Интеллектуальное составление сборок:** ИИ автоматически создает сложные составные изделия, учитывая взаимную техническую сочетаемость компонентов.
- **Интеграция каналов связи (Email / Мессенджеры):** ИИ анализирует входящие сообщения, автоматически подбирает оборудование и формирует два связанных документа: «Запрос клиента» и «Подбор по запросу клиента».
- **Рабочее место с запросами:** сквозной интерфейс для ведения, ручной корректировки, согласования и конвертации запросов в КП.
- **Версионирование и отслеживание изменений**, протоколирование причин изменений.

### 1.5. Интеграции

- **Синхронизация с 1С/CRM:** двусторонняя связь личной номенклатуры, автоматический обмен ценами, персональными скидками, резервами и складскими остатками в реальном времени.
- **Интеграция с системой поиска тендеров** — получение номенклатуры тендерной документации для формирования Запроса клиента, автоматического составления технического предложения, формирования основы для коммерческого предложения, формирования пакета документов для подачи в тендер – файлов сертификатов, чертежей, схем, техничек и каталогов.
- **интеграция с Битрикс24** (лиды, контакты, сделки, КП, состав заказа/сборки).

### 1.6. Обработка и хранение медиа

- **Автоматический перевод чертежей и электрических схем в векторный формат** с сохранением исходного изображения — улучшает воспроизведение и позволяет использовать зашумлённые/нерезкие изображения.
- **Фотогалерея**, оптимизированная для быстрой загрузки, с возможностью получения оригинала.
- **Кадрирование и автоматическая уборка фона** — позволяет накладывать изображения на любые другие и использовать для печатных вариантов.
- **Возможность хранения документации и изображений на своём сервере** — в облаке или локально.
- ** Хранение и выдача 3D и BIM-моделей** в любых форматах.

### 1.7. Корзина и оформление заказа

- **Сбор корзины** с товарами от разных селлеров, дилеров и производителей, включая готовые инженерные сборки.
- **Алгоритм разделения заказа (split):**
  - Готовые сборки напрямую уходят селлеру (инжиниринговой компании).
  - Для «россыпи» — два варианта на выбор:
    1. Через Агрегатора поставок (единый счёт, одна доставка)
    2. Прямая закупка у производителей/дилеров (заказ дробится, клиент работает с каждым поставщиком отдельно)
- **выбор поставщика** — после заполнения корзины клиенту предлагается отправить заявки производителю или поставщикам (выбор из списка, фильтр по регионам).

### 1.8. AI/LLM — технологическая база

- **Function Calling** — информация с сайта структурирована так, что любая LLM (GPT-4, Claude, Llama, Qwen) может:
  1. Понять запрос пользователя
  2. Вызвать `search_equipment(params)`через API системы
  3. Получить ответ в виде списков точного совпадения по нужным параметрам ({exact: [...]) и списка совместимого оборудования (compatible: [...]})
  4. Сформулировать ответ с объяснением
- **Масштабирование и повторное использование** — пользователи могут писать собственных агентов для автоматизации работы.
- **Развитие собственных моделей** на основе ответов LLM:
  - Обработка опросных листов и «диких» запросов технически слабых клиентов
  - Создание компактной специализированной модели для анализа ОЛ и составления структурированного ОЛ
  - Создание модели для квалификации заявки
  - Накопление материала для обучения более продвинутых LLM
  - Локальная модель продолжает работать при отсутствии доступа к коммерческим LLM
  - Экономия затрат на доступ к LLM
- **специализированное обучение на техническом русском, жаргоне, ГОСТ** — на выходе структурированный JSON для отображения на сайтах.

### 1.9. Модель монетизации (в процессе обсуждения)

- **Случайные посетители:** фримиум + продажа информации (на примере auto.ru).
- **Производители:** взнос на поддержание, оплата дискового пространства, размещение на сайте партнёра, карточки товара, включение в ИИ-поиск, подключённый партнёр, заявка с главного сайта, покупка аналитики, адаптация сайтов, интеграция с 1С и Битрикс24.
- **Сайты партнёров:** оборудование от производителя — бесплатно при авторизации производителем или опции «раздача всем»; платно, если производитель не партнёр. Работа с ИИ — по количеству токенов.
- **Профучастники:** ежемесячный взнос (пакет пользователей), оплата за подбор (пакет/нелимитировано/поштучно), адаптация сайтов, интеграция с 1С и Битрикс24, аукцион по выполнению продажи с сайта.

## 2. Преимущества для пользователей системы

### 2.1. Производители оборудования (и Импортёры)

- **Самостоятельное управление техдокументацией:** определять объём и вид документации на сайте — каталоги, 3D и BIM-модели в любых форматах (для серии или для отдельной модели).
- **Фотогалерея** с автоматической оптимизацией, кадрированием и уборкой фона.
- **Автоматический перевод чертежей в векторный формат** — улучшение визуального воспроизведения, работа с зашумлёнными исходниками.
- **«Собственная номенклатура»** — приватные каталоги оборудования для своих сотрудников и избранных партнёров.
- **Конфигуратор цен** с автоматическим расчётом цены на сложное оборудование (пневмоприводы, электроприводы, позиционеры, клапаны соленоидные).
- **AI-помощник** для подбора сложного оборудования.
- **Формирование EBOM, MBOM, КП, спецификаций.**
- **Единая библиотека технической информации** — всегда актуальна, выкладка непосредственно от производителя конечному потребителю.
- **Единые цены** на всех сайтах на основе РРЦ. Цена может быть выше, но не ниже РРЦ — контролируется системой. Валютные цены обновляются централизованно. Нет демпинга и ошибок обновления.
- **Получение аналитики:** количество запросов с сайтов дистрибьюторов, товарные группы, географический интерес конечных потребителей.
- **Анализ плюсов и минусов своей продукции** в сравнении с конкурентами и ценами конкурентов.
- **Оперативный ввод новых продуктовых линеек в систему с немедленным масштабированием по всем пользователям системы ** без необходимости индивидуального продвижения.
- **кастомные AI-обработчики запросов клиентов** — использование собственных нейросетей, выдающих ответ на собственных сайтах или сайтах – партнерах с учетом особенностей оборудования Производителя.

### 2.2. Инжиниринговые компании (технические эксперты платформы)

- **Создание сложных технических сборок** (запорная арматура + электропривод + датчики + крепёж) и продажа комплекта как единого изделия под собственной карточкой товара.
- **Формирование BOM/EBOM** с наценками, поиском замены по параметрам, сроками поставки по каждой позиции.
- **Автоматический или ручной запрос цены и сроков у производителей** — внутри системы или через почту.
- **Быстрый подбор для тендеров.**
- **Формирование идеального КП.**
- **Интеграция с системой поиска тендеров** — получение номенклатуры.
- **Установка скидок и наценок** к базовым РРЦ для выбранных клиентов — автоматическое формирование КП.
- **Ограничение отображаемых разделов каталогов** для сотрудников по брендам/сериям, расстановка приоритетов для подбора.
- **Приватные каталоги** — не на сайте, но доступны сотрудникам и участвуют в подборах.
- **Приватный список номенклатуры** с синхронизацией с 1С и номенклатурой сайта.
- **Формирование BOM/EBOM КП без указания артикула производителя.**
- **Кастомные паспорта товара** под собственными артикулами, кастомные каталоги, кастомные технические документы.
- **Кастомные электрические схемы подключения и габаритные чертежи.**
- **ИИ-аудит сборок** на корректность кодировок и сочетаемость компонентов.
- **Распознавание спецификаций** (Excel, PDF, сканы) и автоматическое формирование «Запроса клиента».
- **Интеграция email/мессенджеров** — ИИ подбирает оборудование из каталога по входящим сообщениям.
- **Рабочее место с запросами** — ведение, корректировка, согласование, конвертация в КП.
- **Синхронизация с 1С/CRM** — цены, скидки, резервы, остатки в реальном времени.
- **проектирование нестандартных МК, скоб, адаптаций** — библиотека и автоматизация.
- **комплектация и MBOM** — поиск аналогов по наличию, ценам, срокам.

### 2.3. Дилеры производителей и Селлеры

- **Размещение карточек товаров** со своими ценами и остатками на Маркете.
- **Прямая ответственность за поставку.**
- **Возможность создать для клиента идеальное КП.**
- **Получение заказов с Сайта-агрегатора.**
- **Доступ к ИИ-модулю** для автоматизации обработки входящих заявок.
- **Установка скидок и наценок** для выбранных клиентов.
- **Синхронизация каталогов** с номенклатурой в 1С/CRM.
- **расстановка приоритетов подбора** — преимущество собственной продукции в выдаче.

### 2.4. Сайты-партнёры (дистрибьюторы)

- **Выкладка полноценного каталога** с инженерными фильтрами на собственный сайт без усилий — быстрое развёртывание (минуты, а не дни/месяцы).
- **Установка наценки** к базовым РРЦ производителей для своего сайта.
- **Автоматический пересчёт валютных цен** в рубли или другую валюту, выбор валюты отображения.
- **Выкладка по видам оборудования** — одно мини-приложение = один раздел на сайте.
- **Выбор брендов и серий** из списка доступных на тарифе (бесплатные, платные, требующие разрешения производителя).
- **Отсутствие необходимости** поддерживать базу по товарам и ценам в актуальном виде.
- **Профессиональный поиск по параметрам**, а не общий от CMS.
- **Входящие заказы** обрабатываются по внутренним правилам локальной CMS.
- **сбор локальных заявок** на своём сайте.

### 2.5. Конечные потребители (B2B-покупатели)

- **Неавторизованный пользователь:**
  - Свободный просмотр каталогов, фильтры, карточки товаров (базовые позиции и готовые сборки).
  - Сбор корзины с товарами от разных селлеров и производителей.
  - Выбор схемы закупки: через Агрегатора (единый счёт) или напрямую у дилеров.
- **Авторизованный пользователь (профессиональный B2B-клиент):**
  - Полный доступ к публичным каталогам, ценам, складским остаткам.
  - Интерактивные конфигураторы для проектирования сложных изделий.
  - ИИ-модуль (аудит сборок, распознавание спецификаций, интеграция каналов связи).
  - Синхронизация с 1С/CRM.
- **Настраиваемые системные виджеты** (курсы валют, справочник химстойкости, расшифровка ЕТТ, документы из медиабиблиотеки), добавление кастомных виджетов (Markdown, PDF, изображения).
- **Получение полной технической информации** об арматуре и устройствах управления.
- **Поиск и подбор по техническим характеристикам**, адаптированный как для профессионалов, так и для людей без специального образования.
- **самостоятельный выбор готовых решений** — конечный потребитель может выбрать готовую сборку без помощи инженера.

### 2.6. Поставщик-консолидатор (Агрегатор поставок)

- **Роль «одного окна»** для конечного покупателя:
  - Консолидация под заявку клиента оборудования от множества разных производителей и селлеров.
  - Получение единой оплаты.
  - Проверка инженерной совместимости оборудования.
  - Контроль качества, переупаковка.
  - Отгрузка всего заказа одной партией (один пакет документов) в адрес клиента.
- **взятие на себя валютных рисков, разных сроков поставки**, складского и логистического хозяйства.

### 2.7. Тендерные отделы и снабженцы
- ** Автоматическое получение тендерной документации ** из партнерской системы парсинга тендеров в компактном и читаемом виде, пригодном для передачи в подбор оборудования.
- **Обработка тендерной документации** — ИИ анализирует тендер, формирует EBOM.
- **Быстрый подбор для тендеров** — поиск по номенклатуре тендера, автоматическое сопоставление с каталогом.
- **Аукцион/биржа EBOM** — раздел «Получить решение»: заказчик вводит требования, ИИ создаёт EBOM и выставляет на биржу для выполнения селлерами.

## Резюме (из текста)

- Заниматься прямой продажей с сайта можно, но для этого нужна инфраструктура, подобная маркетплейсу — риски и сложность высоки.
- Возникает вопрос предпочтений агрегатора к разным поставщикам, что снижает доверие.
- **Альтернатива:** клиенту предоставляется выбор поставщика; сайт-агрегатор не продаёт сам, а даёт информацию и связывает покупателя с продавцом.
- **Зачем нужна витрина на главном сайте:**
  - Агрегированный источник технических характеристик — клиент не обязан обходить сайты всех производителей.
  - Оперативный ввод новых продуктовых линеек.
  - Продвижение товара в поисковиках.
  - Наличие интерфейса для ИИ (schema, агенты для автоматического поиска и заказа).
  - Сбор маркетинговой информации об интересе к товарам с определёнными характеристиками.
- **Проект лучше реализовывать совместно с производителями оборудования** — доступ к актуальной техинформации, ввод новых серий, актуальность цен и остатков.
