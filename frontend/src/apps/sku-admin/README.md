**Дата:** 2026-05-22
**Стек:** Vue 3 `<script setup>`, Vite 6, axios

| Файл | Назначение |

## Вкладки

### Список
- Таблица: код, название, тип, бренд, количество цен, активность
- Фильтры: поиск (code/name), тип оборудования, бренд
- Кнопка «+ Создать» — открывает SkuForm

### Групповая обработка
- Фильтры: код (подстрока), тип (с «не указано»), бренд (с «не указано»)
- Кнопка «Отобрать по фильтрам» — полное обновление списка
- Чекбоксы, «Выделить всё/Снять выделение»
- Селекторы: «Тип: не менять», «Бренд: не менять»
- Кнопка «Записать» — POST `/api/admin/sku/batch/`

### Форма CRUD
- Поля: код, название, описание, тип оборудования, бренд, активность
- Кнопки: Сохранить, Удалить (для существующих), Отмена
- create/update через UniversalAPIView (`/api/core/`)

## API

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/admin/sku/` | Список с фильтрами |
| POST | `/api/admin/sku/batch/` | Групповое обновление |
| CRUD | `/api/core/` | Через UniversalAPIView |
