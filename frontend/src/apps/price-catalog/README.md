# Цены — мини-приложение (Vue 3)

Каталог цен и журнал документов формирования цен.

**Дата:** 2026-05-22
**Стек:** Vue 3 `<script setup>`, Vite 6, axios

---

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Точка входа Vite |
| `main.js` | `createApp(App).mount('#price-app')` |
| `App.vue` | Вкладки: Каталог + Документы, provide opts/contentTypes |
| `api.js` | API-вызовы к `/api/admin/prices/` |
| `components/PriceCatalog.vue` | Таблица цен с фильтрами |
| `components/DocumentJournal.vue` | Журнал документов + создание |
| `components/DocumentCard.vue` | Редактор документа |

---

## Вкладки

### Каталог цен
- Таблица: название, код, вид, валюта, цена, дата, актуальность
- Фильтры: поиск, тип оборудования, бренд, вид цены, валюта, даты

### Документы
- Таблица: название, дата, позиций, статус (цветной)
- Создание: название + дата (тип оборудования убран — позиции через SKU)
- Кнопки: Провести, Отмена проведения, Удалить

### Редактор документа
- Шапка: название, тип цены, валюта, дата (редактируемые в draft)
- Таблица позиций с инлайн-редактированием цены (клик → ввод → Enter)
- Поиск товара через `/api/admin/sku/?search=`
- Кнопка «+ Добавить» — добавить выбранный SKU
- Кнопка «+ Создать и добавить» — создать SKU и сразу в документ
- Кнопка 📝 — модалка редактирования SKU
- Статус-бейджи, кнопки: На согласование, Провести, Отмена, Удалить
- Кнопки: На согласование → Провести → Отмена проведения
