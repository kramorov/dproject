## 2. Преимущества для пользователей системы

### 2.1. Производители оборудования (и Импортёры)

- **Самостоятельное управление техдокументацией:** определять объём и вид документации на сайте — каталоги, 3D и BIM-модели в любых форматах (для серии или для отдельной модели).
- **«Собственная номенклатура»** — приватные каталоги оборудования для своих сотрудников и избранных партнёров.
- **Оперативный ввод** новых продуктовых линеек в систему с немедленным масштабированием по всем пользователям системы без необходимости индивидуального продвижения.
- **Контроль РРЦ** установленные производителем на агрегаторе цены транслируются немедленно на сайты-партнеры на основе РРЦ. Цена может быть выше, но не ниже РРЦ — контролируется системой. Валютные цены обновляются централизованно. Нет демпинга и ошибок обновления.
- **Конфигуратор цен** с автоматическим расчётом цены на сложное оборудование (пневмоприводы, электроприводы, позиционеры, клапаны соленоидные).
- **AI-помощник** для подбора сложного оборудования.
- **Кастомные AI-обработчики запросов клиентов** — использование собственных нейросетей, выдающих ответ на собственных сайтах или сайтах – партнерах с учетом особенностей оборудования Производителя.
- **Единая библиотека технической информации** — всегда актуальна, выкладка непосредственно от производителя конечному потребителю.
- **Единые цены** на всех сайтах 
- **Получение аналитики:** количество запросов с сайтов дистрибьюторов, товарные группы, географический интерес конечных потребителей.
- **Анализ плюсов и минусов своей продукции** в сравнении с конкурентами и ценами конкурентов.

### 2.2. Инжиниринговые компании (технические эксперты платформы)

- **Создание сложных технических сборок** (запорная арматура + электропривод + датчики + крепёж) и продажа комплекта как единого изделия под собственной карточкой товара.
- **Формирование BOM/EBOM** с наценками, поиском замены по параметрам, сроками поставки по каждой позиции.
- **Автоматический или ручной запрос цены и сроков у производителей** — внутри системы или через почту.
- **Быстрый подбор для тендеров.**
- **Формирование идеального КП.**
- **Интеграция с системой поиска тендеров** — получение номенклатуры.
- **Установка скидок и наценок** к базовым РРЦ для выбранных клиентов — автоматическое формирование КП.
- **Ограничение отображаемых разделов каталогов** для сотрудников по брендам/сериям, расстановка приоритетов для подбора.
- **Приватные каталоги** — не на сайте, но доступны сотрудникам и участвуют в подборах.
- **Приватный список номенклатуры** с синхронизацией с 1С и номенклатурой сайта.
- **Формирование BOM/EBOM КП без указания артикула производителя.**
- **Кастомные паспорта товара** под собственными артикулами, кастомные каталоги, кастомные технические документы.
- **Кастомные электрические схемы подключения и габаритные чертежи.**
- **ИИ-аудит сборок** на корректность кодировок и сочетаемость компонентов.
- **Распознавание спецификаций** (Excel, PDF, сканы) и автоматическое формирование «Запроса клиента».
- **Интеграция email/мессенджеров** — ИИ подбирает оборудование из каталога по входящим сообщениям.
- **Рабочее место с запросами** — ведение, корректировка, согласование, конвертация в КП.
- **Синхронизация с 1С/CRM** — цены, скидки, резервы, остатки в реальном времени.
- **Проектирование нестандартных МК, скоб, адаптаций** — библиотека и автоматизация.
- **Комплектация и MBOM** — поиск аналогов по наличию, ценам, срокам.

### 2.3. Дилеры производителей и Селлеры

- **Размещение карточек товаров** со своими ценами и остатками на Маркете.
- **Получение заказов с Сайта-агрегатора.**
- **Быстрая и легкая** комплектация комплексного заказа через агрегатор.
- **Возможность создать для клиента идеальное КП.**
- **Доступ к ИИ-модулю** для автоматизации обработки входящих заявок.
- **Установка скидок и наценок** для выбранных клиентов.
- **Синхронизация каталогов** с номенклатурой в 1С/CRM.
- **Расстановка приоритетов подбора** — преимущество собственной продукции в выдаче.

### 2.4. Сайты-партнёры (дистрибьюторы)

- **Выкладка полноценного каталога** с инженерными фильтрами на собственный сайт без усилий — быстрое развёртывание (минуты, а не дни/месяцы).
- **Установка наценки** к базовым РРЦ производителей для своего сайта.
- **Автоматический пересчёт валютных цен** в рубли или другую валюту, выбор валюты отображения.
- **Выкладка по видам оборудования** — одно мини-приложение = один раздел на сайте.
- **Выбор брендов и серий** из списка доступных на тарифе (бесплатные, платные, требующие разрешения производителя).
- **Отсутствие необходимости** поддерживать базу по товарам и ценам в актуальном виде.
- **Профессиональный поиск по параметрам**, а не общий от CMS.
- **Входящие заказы** обрабатываются по внутренним правилам локальной CMS.
- **Сбор локальных заявок** на своём сайте.

### 2.5. Конечные потребители (B2B-покупатели)

- **Неавторизованный пользователь:**
  - Свободный просмотр каталогов, фильтры, карточки товаров (базовые позиции и готовые сборки).
  - Сбор корзины с товарами от разных селлеров и производителей.
  - Выбор схемы закупки: через Агрегатора (единый счёт) или напрямую у дилеров.
- **Авторизованный пользователь (профессиональный B2B-клиент):**
  - Полный доступ к публичным каталогам, ценам, складским остаткам.
  - Интерактивные конфигураторы для проектирования сложных изделий.
  - ИИ-модуль (аудит сборок, распознавание спецификаций, интеграция каналов связи).
  - Синхронизация с 1С/CRM.
- **Настраиваемые системные виджеты** (курсы валют, справочник химстойкости, расшифровка ЕТТ, документы из медиабиблиотеки), добавление кастомных виджетов (Markdown, PDF, изображения).
- **Получение полной технической информации** об арматуре и устройствах управления.
- **Поиск и подбор по техническим характеристикам**, адаптированный как для профессионалов, так и для людей без специального образования.
- **самостоятельный выбор готовых решений** — конечный потребитель может выбрать готовую сборку без помощи инженера.

### 2.6. Поставщик-консолидатор (Агрегатор поставок)

- **Роль «одного окна»** для конечного покупателя:
  - Консолидация под заявку клиента оборудования от множества разных производителей и селлеров.
  - Получение единой оплаты.
  - Проверка инженерной совместимости оборудования.
  - Контроль качества, переупаковка.
  - Отгрузка всего заказа одной партией (один пакет документов) в адрес клиента.
- **взятие на себя валютных рисков, разных сроков поставки**, складского и логистического хозяйства.

### 2.7. Тендерные отделы и снабженцы
- **Автоматическое получение тендерной документации** из партнерской системы парсинга тендеров в компактном и читаемом виде, пригодном для передачи в подбор оборудования.
- **Обработка тендерной документации** — ИИ анализирует тендер, формирует EBOM.
- **Быстрый подбор для тендеров** — поиск по номенклатуре тендера, автоматическое сопоставление с каталогом.
- **Аукцион/биржа EBOM** — раздел «Получить решение»: заказчик вводит требования, ИИ создаёт EBOM и выставляет на биржу для выполнения селлерами.
