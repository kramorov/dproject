Open WebUI (ранее Ollama WebUI) – Лучший вариант
🔹 Ссылка: GitHub - Open WebUI
🔹 Особенности:

Полноценный веб-интерфейс для Ollama (аналог ChatGPT)

Поддержка локальных и облачных моделей (Llama 3, CodeLlama, Mistral и др.)

Возможность загрузки документов (PDF, TXT)

Групповые чаты, мультимодальность (если модель поддерживает)

Как установить:

Запустите Ollama локально (ollama serve).

Установите Docker и запустите Open WebUI:

bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
Откройте http://localhost:3000 в браузере.

Создаем новый проект
в нем запускаем в терминале:
npx create-nuxt-app nuxt-apollo-vuetify
 Вручную (если проект уже есть):
//npm init nuxt-app nuxt-apollo-vuetify
npm i -D @nuxtjs/apollo@next

Это создает проект nuxt-app
cd nuxt-app
Добавляем Apollo (@nuxtjs/apollo)
Настраиваем Apollo в nuxt.config.js
export default {
  modules: [
    '@nuxtjs/apollo',
    '@nuxtjs/vuetify'
  ],
  apollo: {
    clientConfigs: {
      default: {
        httpEndpoint: 'https://your-graphql-api.com/graphql' // ваш GraphQL-эндпоинт
      }
    }
  }
}

Проверяем Vuetify
Если при создании проекта выбрали Vuetify, он уже настроен.
Если нет — установите:
npm install @nuxtjs/vuetify

Добавьте в nuxt.config.js:
export default {
  modules: ['@nuxtjs/vuetify']
}
