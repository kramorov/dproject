## Что сделано за сессию

1. **Концепция и режимы выбора** (slots.md §1): глоссарий переписан —
   «Узел = логическое объединение параметров; Слот = описание сущности без
   строки в БД; Опция = физическое значение справочника». Режим `bundle`
   удалён из словаря (single/multi/xor; multi — осознанное исключение),
   миграция 0021. Матричный bundle остался (пакет MWG = «именованный
   фрагмент конфигурации»).
2. **§4.2–4.4 выполнены**: `CuSlot.source` (CuSlotSource +
   `SLOT_SOURCE_PAYLOAD`, миграция 0022) — object-слот объявляет
   справочник-источник; опции — срез записей справочника, kind выводится
   сервером; value-слоты — только none/pair. Миграция 0023 (kind
   access_device + поле). Сид приводит флаги: 40 object / 2 value
   (TURN_COUNTER, MOTOR_STARTER).
3. **Фронт**: две карточки опций (value — имя/описание; object — режим
   «значение из справочника / „Нет“», превью name/description записи,
   код опции авто из кода записи и скрыт); добавление опции object-слота
   — селект «+ Добавить из справочника…» (неиспользованные записи) +
   кнопка «+ „Нет“». Превью БУ: слот без доступных опций скрыт, «один std»
   — read-only.
4. **API исполняет model.clean()** (review-фикс): `_clean_via_model` в
   сериализаторах слота/опции; meta отдаёт selection_modes/slot_kinds/
   slot_sources (единый источник). Починено каскадное удаление фронта
   (двойной `/api/api/` в guardedDelete).
5. **Слот ACCESS_DEVICE** («Устройство ограничения доступа», узел местной
   индикации): источник access_device → общая модель ЭП
   `EaAccessDeviceOption` (NO_DEVICE/DEVICE, ext AD0/AD1); профили как в
   legacy (INT-линейка — оба варианта, basic/позиционер — «нет»).
6. **Узел «Датчики» восстановлен как канон** (после ложной stale-чистки;
   исходный дизайн найден в git e0a1849): SENSOR — тип датчика, не сигнал.
   7 слотов object/device: концевые/путевые/моментные × основные/доп.
   (`END_/WAY_/TORQUE_SWITCHES_SENSOR_MAIN/EXT`) + `THERMO_SENSOR`
   (термореле THERMO / PTC-термистор PTC_THERMISTOR / нет). Опции — MECH
   «Механические»/ENC «Энкодер»/«Нет датчика» с префиксными кодами.
   `stale_slots` сокращён до явного мусора (сид больше не удаляет
   осознанный дизайн).
7. **Справочник control-signals вычищен**: wires=2 явно (была дыра —
   устаревшая CMD_4_20_ACTIVE с wires=None); устаревшие уставки старого
   поколения имён и опция-дубль SETPOINT удалены. Канон: CMD_4_20MA /
   CMD_4_20MA_HART.
8. **Сид каноничен и идемпотентен**: 8 БУ, 42 слота, 142 опции,
   556 строк, 26 правил (двойной прогон стабилен). Тесты **122/122**
   (ea_control 68, electric_actuators 54), `npm run build` успешно.
